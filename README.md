# Bot OSINT de Telegram para Termux

Bot que extrae información de usuarios de Telegram usando Pyrogram con tu
cuenta propia. Permite resolver @usernames a ID numérico y obtener el perfil
completo (nombre, bio, foto, estado, premium, verificación).

## Requisitos

- Termux (Android) con Python
- Credenciales de API de Telegram: <https://my.telegram.org>
